# Company Creation and Database Provisioning (Backend) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A logged-in user can create a company through the API; the API then creates that company's database on the configured SQL server by itself, and the company becomes usable when the database is ready.

**Architecture:** `create-company` writes the company (status `Provisioning`), its creator as Admin and the Service module in one main-database transaction and returns at once. An in-process background worker then creates an empty database with a server-generated name on the default server from the new `DbServers` table, runs the existing `New_Tenant_Database.sql` on it, and marks the company `Ready` (or drops the database it created and marks it `Failed`). The decision logic is a small orchestrator behind two interfaces so it is unit-tested with fakes; the SQL-bound parts are thin.

**Tech Stack:** SQL Server scripts, ASP.NET Core (.NET 10), ADO.NET (`Microsoft.Data.SqlClient`), `BackgroundService` + `System.Threading.Channels`, xUnit.

**Spec:** `docs/superpowers/specs/2026-10-11-saas-tenancy-design.md` (sections 4.1, 4.2, 5, 10, 11; decisions D5-D9, D13)

**Plan series:**

## Global Constraints

- The SQL Server in `EncryptzAPI/appsettings.json` is LIVE. Only `MainDBEncryptz` and `HamsterserviceDB` may be touched, and only with read-only `SELECT`. Never run a script from this plan or any repo script against it. Never run `dotnet run`. Do not open or print `appsettings.json`. Nothing in this plan is executed against a database by the assistant: no `CREATE DATABASE`, no test databases.
- Every SQL change is a NEW file in the repo whose name starts with a number. In `EncryptzAPI/Database/MainDB/` numbers `01`-`19` are used and FROZEN: never edit them. This plan adds `20`. Next free number after this plan: `21`. An SQL file is frozen once the task that creates it is complete.
- No existing `.sql` file is changed. In particular `EncryptzAPI/Database/ProjectDB/New_Tenant_Database.sql` and `Build-NewTenantScript.ps1` stay exactly as they are (ruling: the spec's section 5.3 change of the build script is replaced by the API supplying the settings itself, see Task 3).
- New SQL scripts contain no `USE`, `CREATE DATABASE`, `DROP DATABASE` or `DROP TABLE`. They refuse to run in a system database or without `dbo.Companies`. They are re-runnable.
- A database name is generated by the server from the company id only (`EncryptzTenant_` + six digits). No text typed by a user is ever placed in a database name or concatenated into SQL. Everything else reaches SQL as a parameter.
- The API drops a database ONLY when the same provisioning attempt created it. A database that already exists under the generated name is never dropped and never reused: the attempt fails.
- Messages returned to users never contain server names, database names, logins, or SQL / exception text. Detail goes to `Companies.ProvisionError` (platform administrators only) and the log.
- Passwords are stored only encrypted (`ITenantSecretProtector`) and never returned by any endpoint or written to a log.
- One login per server (decision D7): the login in `DbServers` creates the database and is stored on the company row as its connection login.
- Company creation does nothing until a platform administrator has added an active default row to `DbServers`: until then it answers "Company creation is not available right now".
- Only platform administrators manage `DbServers` and `PlatformSettings` (`[Authorize]` + `[PlatformUnlocked]` + `PlatformActor.IsPlatformAdmin`).
- Match the surrounding code style. Do not reformat files you touch. Keep each file's encoding and line endings.
- Run commands from the repository root `D:\Encryptz\ServiceManagement`: `dotnet build EncryptzAPI/EncryptzAPI.csproj`, `dotnet test EncryptzTests/EncryptzTests.csproj` (baseline: 116 tests pass).

## Review Focus

1. The same user sends two create-company requests at the same moment with a limit of 1: only one company may be created. Enforced inside `sp_Company_Create` with an application lock (Task 2); the limit arithmetic is pinned in Task 1.
2. A database with the generated name already exists on the server (left over from an attempt whose clean-up failed, or made by hand): it must not be dropped and not be reused. Pinned in Task 4.
3. The tenant script fails or times out half-way: the database created by this attempt is dropped, the company is `Failed`, the stored error is for platform administrators only. Pinned in Task 4.
4. The API restarts during a job, or a job finishes after the sweeper has already marked the company `Failed`: the company must not become `Ready` behind the user's back with a half-built database; the late job drops its database. Pinned in Task 4 (`CompleteAsync` returns false) and Task 6 (sweeper).
5. Hostile or sloppy input: a company code or branch name with quotes, brackets, semicolons, control characters or 5,000 characters; a "lookup source" setting such as `x]; DROP DATABASE y--`. Refused or passed as parameters, never concatenated. Pinned in Task 1.

```csharp
using System.Text.RegularExpressions;

namespace EncryptzBL.Common.Provisioning
{
    /// <summary>
    /// The name of a company's database. It is made from the company id only, so
    /// nothing a user typed can ever be part of a database name.
    /// </summary>
    public static class TenantDatabaseName
    {
        private const string Prefix = "EncryptzTenant_";
        private static readonly Regex Generated = new(@"^EncryptzTenant_[0-9]{6,10}$", RegexOptions.CultureInvariant);

        public static string For(int companyId)
        {
            if (companyId <= 0)
                throw new ArgumentOutOfRangeException(nameof(companyId));

            return Prefix + companyId.ToString("D6", System.Globalization.CultureInfo.InvariantCulture);
        }

        /// <summary>True only for a name <see cref="For"/> can produce.</summary>
        public static bool IsGenerated(string? name)
        {
            if (string.IsNullOrEmpty(name) || !Generated.IsMatch(name))
                return false;

            return long.TryParse(name.AsSpan(Prefix.Length), out var id) && id > 0 && id <= int.MaxValue
                   && For((int)id) == name;
        }
    }
}
```

```csharp
using System.Text.RegularExpressions;

namespace EncryptzBL.Common.Provisioning
{
    /// <summary>
    /// Splits a script at its batch separators: lines that hold nothing but GO.
    /// (GO is a tool command, not SQL: the server does not understand it.)
    /// </summary>
    public static class SqlBatchSplitter
    {
        private static readonly Regex Separator = new(@"^[ \t]*GO[ \t]*$",
            RegexOptions.Multiline | RegexOptions.IgnoreCase | RegexOptions.CultureInvariant);

        public static IReadOnlyList<string> Split(string script)
        {
            if (string.IsNullOrWhiteSpace(script))
                return Array.Empty<string>();

            var text = script.Replace("\r\n", "\n").Replace('\r', '\n');

            return Separator.Split(text)
                .Select(batch => batch.Trim('\n', ' ', '\t'))
                .Where(batch => batch.Length > 0)
                .ToList();
        }
    }
}
```

```csharp
using System.Text.RegularExpressions;

namespace EncryptzBL.Common.Provisioning
{
    /// <summary>A create-company request after trimming and checking.</summary>
    public sealed record NewCompany(
        string CompanyName, string CompanyCode, string FirstBranchName,
        string? Address, string? City, string? PhoneNumber);

    /// <summary>
    /// What a user may send to create a company. Free text is only ever passed to
    /// SQL as a parameter, so quotes and brackets are harmless; control characters
    /// and over-long text are refused. The company code is restricted because it is
    /// typed by customers on the portal login.
    /// </summary>
    public static class CompanyCreateRules
    {
        public const string DefaultBranchName = "Head Office";

        private static readonly Regex Code = new(@"^[A-Z0-9][A-Z0-9_-]{1,19}$", RegexOptions.CultureInvariant);

        public static (NewCompany? Company, string? Error) Normalize(
            string? name, string? code, string? branch, string? address, string? city, string? phone)
        {
            var companyName = (name ?? "").Trim();
            if (companyName.Length < 2)
                return (null, "Enter the company name");

            var raw = (code ?? "").Trim();
            // checked before upper-casing: only plain letters may become A-Z
            var companyCode = raw.All(ch => ch < 128) ? raw.ToUpperInvariant() : raw;
            if (!Code.IsMatch(companyCode))
                return (null, "The company code must be 2 to 20 letters, digits, - or _ and start with a letter or digit");

            var branchName = string.IsNullOrWhiteSpace(branch) ? DefaultBranchName : branch.Trim();

            var addressText = Optional(address);
            var cityText = Optional(city);
            var phoneText = Optional(phone);

            if (TooLong(companyName, 200) || TooLong(branchName, 200) || TooLong(addressText, 400)
                || TooLong(cityText, 100) || TooLong(phoneText, 30))
                return (null, "One of the values is too long");

            if (HasControl(companyName) || HasControl(branchName) || HasControl(addressText)
                || HasControl(cityText) || HasControl(phoneText))
                return (null, "One of the values contains characters that are not allowed");

            return (new NewCompany(companyName, companyCode, branchName, addressText, cityText, phoneText), null);
        }

        /// <summary>Null when the user may create another company.</summary>
        public static string? LimitMessage(int created, int limit, bool isPlatformAdmin)
        {
            if (isPlatformAdmin)
                return null;

            if (limit <= 0)
                return "Company creation is not available right now";

            if (created < limit)
                return null;

            return limit == 1
                ? "You can create 1 company. You have reached the limit."
                : $"You can create {limit} companies. You have reached the limit.";
        }

        private static string? Optional(string? value)
            => string.IsNullOrWhiteSpace(value) ? null : value.Trim();

        private static bool TooLong(string? value, int max) => value != null && value.Length > max;

        private static bool HasControl(string? value) => value != null && value.Any(char.IsControl);
    }
}
```

```csharp
using System.Globalization;
using System.Text.RegularExpressions;

namespace EncryptzBL.Common.Provisioning
{
    /// <summary>The platform settings that exist and what their values may be.</summary>
    public static class PlatformSettingRules
    {
        /// <summary>How many companies one user may create (platform administrators are exempt).</summary>
        public const string MaxCompaniesPerUser = "MaxCompaniesPerUser";

        /// <summary>
        /// A database on the tenant server whose lookup rows (roles, statuses, settings,
        /// menus) a new company database starts with. Empty = the script's built-in defaults.
        /// </summary>
        public const string TenantLookupSourceDb = "TenantLookupSourceDb";

        private static readonly Regex DatabaseName = new(@"^[A-Za-z0-9_]{1,128}$", RegexOptions.CultureInvariant);
        private static readonly string[] SystemDatabases = { "master", "model", "msdb", "tempdb" };

        /// <summary>The value to store, or the reason it is refused.</summary>
        public static (string? Value, string? Error) Validate(string? key, string? value)
        {
            var text = (value ?? "").Trim();

            switch (key)
            {
                case MaxCompaniesPerUser:
                    return int.TryParse(text, NumberStyles.None, CultureInfo.InvariantCulture, out var n) && n <= 100
                        ? (n.ToString(CultureInfo.InvariantCulture), null)
                        : (null, "Enter a number from 0 to 100");

                case TenantLookupSourceDb:
                    if (text.Length == 0)
                        return ("", null);

                    if (!DatabaseName.IsMatch(text)
                        || SystemDatabases.Contains(text, StringComparer.OrdinalIgnoreCase))
                        return (null, "Enter the plain name of a company database, or leave it empty");

                    return (text, null);

                default:
                    return (null, "Unknown setting");
            }
        }
    }
}
```

```sql
/* How many companies the user has created, the limit and whether a server is

                WHERE s.SettingKey = 'MaxCompaniesPerUser'), 1)                                     AS Limit,

/* The company, its creator as Admin and the Service module, in one transaction.
   The database is created afterwards by the API (status Provisioning).
   Two requests of the same user wait for each other, so the limit holds. */
CREATE OR ALTER PROCEDURE dbo.sp_Company_Create
    @CompanyName     NVARCHAR(200),
    @CompanyCode     NVARCHAR(50),
    @Address         NVARCHAR(400) = NULL,
    @City            NVARCHAR(100) = NULL,
    @PhoneNumber     NVARCHAR(30)  = NULL,
    @FirstBranchName NVARCHAR(200),
    @CreatedBy       INT,
    @IsPlatformAdmin BIT = 0
AS
BEGIN
    SET NOCOUNT ON;
    SET XACT_ABORT ON;

    DECLARE @CompanyId INT, @ServerId INT, @ModuleId INT, @Limit INT, @Created INT, @LockResult INT,
            @Lock NVARCHAR(100) = N'CompanyCreate:' + CAST(@CreatedBy AS NVARCHAR(20)),
            @Message NVARCHAR(200);

    IF NOT EXISTS (SELECT 1 FROM dbo.Users WHERE UserId = @CreatedBy AND IsActive = 1)
    BEGIN
        SELECT CAST(0 AS INT) AS Success, 'User not found' AS Message, CAST(0 AS INT) AS CompanyId; RETURN;
    END

    BEGIN TRY
        BEGIN TRANSACTION;

        /* a negative result means the lock was NOT taken (time-out, deadlock): never go on without it */
        EXEC @LockResult = sp_getapplock @Resource = @Lock, @LockMode = 'Exclusive', @LockOwner = 'Transaction', @LockTimeout = 15000;
        IF @LockResult < 0
        BEGIN
            ROLLBACK TRANSACTION;
            SELECT CAST(0 AS INT) AS Success, 'The company could not be created. Please try again.' AS Message, CAST(0 AS INT) AS CompanyId;
            RETURN;
        END

        SELECT @ServerId = DbServerId FROM dbo.DbServers WHERE IsDefault = 1 AND IsActive = 1;
        SELECT @ModuleId = ModuleId FROM dbo.Modules WHERE ModuleKey = 'SERVICE' AND IsActive = 1;

        SET @Limit = ISNULL((SELECT TRY_CAST(SettingValue AS INT) FROM dbo.PlatformSettings
                             WHERE SettingKey = 'MaxCompaniesPerUser'), 1);
        SET @Created = (SELECT COUNT(*) FROM dbo.Companies
                        WHERE CreatedBy = @CreatedBy AND ProvisionStatus <> 'Failed');

        IF @ServerId IS NULL OR @ModuleId IS NULL OR (ISNULL(@IsPlatformAdmin, 0) = 0 AND @Limit <= 0)
            SET @Message = 'Company creation is not available right now';
        ELSE IF ISNULL(@IsPlatformAdmin, 0) = 0 AND @Created >= @Limit
            SET @Message = 'You have reached the number of companies you can create';
        ELSE IF EXISTS (SELECT 1 FROM dbo.Companies WHERE CompanyCode = @CompanyCode)
            SET @Message = 'This company code is already in use';

        IF @Message IS NOT NULL
        BEGIN
            ROLLBACK TRANSACTION;
            SELECT CAST(0 AS INT) AS Success, @Message AS Message, CAST(0 AS INT) AS CompanyId;
            RETURN;
        END

        INSERT INTO dbo.Companies
               (CompanyName, CompanyCode, Address, City, PhoneNumber, IsActive,
                TenantScopeId, ProvisionStatus, ProvisionStartedAt, CreatedBy, FirstBranchName, DbServerId)
        VALUES (@CompanyName, @CompanyCode, @Address, @City, @PhoneNumber, 1,
                1, 'Provisioning', GETDATE(), @CreatedBy, @FirstBranchName, @ServerId);

        SET @CompanyId = SCOPE_IDENTITY();

        /* the routing key carried in tokens: made from the id, never from typed text */
        UPDATE dbo.Companies
        SET TenantKey = 'T' + CASE WHEN @CompanyId < 1000000
                                   THEN RIGHT('000000' + CAST(@CompanyId AS VARCHAR(10)), 6)
                                   ELSE CAST(@CompanyId AS VARCHAR(10)) END
        WHERE CompanyId = @CompanyId;

        INSERT INTO dbo.CompanyUsers (CompanyId, UserId, RoleInCompany, AssignedBy, IsActive)
        VALUES (@CompanyId, @CreatedBy, 'Admin', @CreatedBy, 1);

        INSERT INTO dbo.CompanyModules (CompanyId, ModuleId, IsEnabled)
        VALUES (@CompanyId, @ModuleId, 1);

        INSERT INTO dbo.UserModuleAccess (CompanyId, UserId, ModuleId, GrantedBy)
        VALUES (@CompanyId, @CreatedBy, @ModuleId, @CreatedBy);

        COMMIT TRANSACTION;

        SELECT CAST(1 AS INT) AS Success, 'Company created. Its database is being set up.' AS Message, @CompanyId AS CompanyId;
    END TRY
    BEGIN CATCH
        IF @@TRANCOUNT > 0 ROLLBACK TRANSACTION;

        /* 2627 / 2601: the code was taken by another request in the same moment */
        SELECT CAST(0 AS INT) AS Success,
               CASE WHEN ERROR_NUMBER() IN (2627, 2601) THEN 'This company code is already in use'
                    ELSE 'The company could not be created. Please try again.' END AS Message,
               CAST(0 AS INT) AS CompanyId;
    END CATCH
END
GO

/* What the worker needs to build the database of a company. */
CREATE OR ALTER PROCEDURE dbo.sp_Provision_GetJob
    @CompanyId INT
AS
BEGIN
    SET NOCOUNT ON;

    SELECT
        c.CompanyId, c.TenantScopeId,
        ISNULL(NULLIF(LTRIM(RTRIM(c.FirstBranchName)), ''), 'Head Office') AS FirstBranchName,
        c.ProvisionStatus,
        ISNULL(s.ServerName, '')       AS ServerName,
        ISNULL(s.AdminUser, '')        AS AdminUser,

        ISNULL(s.ExtraOptions, '')     AS ExtraOptions,

                WHERE p.SettingKey = 'TenantLookupSourceDb'), '') AS LookupSourceDb
    FROM dbo.Companies c
    LEFT JOIN dbo.DbServers s ON s.DbServerId = c.DbServerId AND s.IsActive = 1
    WHERE c.CompanyId = @CompanyId;
END

/* The database is built: the company gets its connection (taken from its
   server row) and becomes Ready. Only a company that is still Provisioning:
   a job that was given up (marked Failed) must not become Ready later. */
CREATE OR ALTER PROCEDURE dbo.sp_Provision_Complete
    @CompanyId    INT,
    @DatabaseName NVARCHAR(200)
AS
BEGIN
    SET NOCOUNT ON;

    UPDATE c
    SET c.ServerName      = s.ServerName,
        c.DatabaseName    = @DatabaseName,
        c.DbUser          = s.AdminUser,
        c.DbPasswordEnc   = s.AdminPasswordEnc,
        c.ExtraOptions    = s.ExtraOptions,
        c.ProvisionStatus = 'Ready',
        c.ProvisionError  = NULL
    FROM dbo.Companies c
    INNER JOIN dbo.DbServers s ON s.DbServerId = c.DbServerId
    WHERE c.CompanyId = @CompanyId
      AND c.ProvisionStatus = 'Provisioning';

    SELECT CAST(CASE WHEN @@ROWCOUNT = 1 THEN 1 ELSE 0 END AS INT) AS Success,
           ISNULL((SELECT TenantKey FROM dbo.Companies WHERE CompanyId = @CompanyId), '') AS TenantKey;
END
GO

CREATE OR ALTER PROCEDURE dbo.sp_Provision_Fail
    @CompanyId INT,
    @Error     NVARCHAR(2000)
AS
BEGIN
    SET NOCOUNT ON;

    UPDATE dbo.Companies
    SET ProvisionStatus = 'Failed',
        ProvisionError  = LEFT(ISNULL(@Error, ''), 2000)
    WHERE CompanyId = @CompanyId
      AND ProvisionStatus = 'Provisioning';
END
GO

/* Try again: only a Failed company, by its creator or a platform administrator.
   The single UPDATE is the gate, so two retries cannot both start a job. */
CREATE OR ALTER PROCEDURE dbo.sp_Provision_Retry
    @CompanyId       INT,
    @UserId          INT,
    @IsPlatformAdmin BIT = 0
AS
BEGIN
    SET NOCOUNT ON;

    DECLARE @ServerId INT = (SELECT DbServerId FROM dbo.DbServers WHERE IsDefault = 1 AND IsActive = 1);

    IF NOT EXISTS (SELECT 1 FROM dbo.Companies
                   WHERE CompanyId = @CompanyId AND IsActive = 1
                     AND (ISNULL(@IsPlatformAdmin, 0) = 1 OR CreatedBy = @UserId))
    BEGIN
        SELECT CAST(0 AS INT) AS Success, 'Company not found' AS Message; RETURN;
    END

    IF @ServerId IS NULL
    BEGIN
        SELECT CAST(0 AS INT) AS Success, 'Company creation is not available right now' AS Message; RETURN;
    END

    UPDATE dbo.Companies
    SET ProvisionStatus = 'Provisioning', ProvisionStartedAt = GETDATE(), DbServerId = @ServerId
    WHERE CompanyId = @CompanyId
      AND ProvisionStatus = 'Failed';

    IF @@ROWCOUNT = 1
        SELECT CAST(1 AS INT) AS Success, 'The database is being set up.' AS Message;
    ELSE
        SELECT CAST(0 AS INT) AS Success, 'This company is not waiting for a retry' AS Message;
END
GO

/* Jobs that were interrupted (API restart, crash): give them up so the user
   can retry. */
CREATE OR ALTER PROCEDURE dbo.sp_Provision_FailStuck
    @OlderThanMinutes INT = 15
AS
BEGIN
    SET NOCOUNT ON;

    UPDATE dbo.Companies
    SET ProvisionStatus = 'Failed',
        ProvisionError  = 'The set-up did not finish (interrupted or timed out).'
    WHERE ProvisionStatus = 'Provisioning'
      AND ISNULL(ProvisionStartedAt, '19000101') < DATEADD(MINUTE, -ABS(ISNULL(@OlderThanMinutes, 15)), GETDATE());

    SELECT @@ROWCOUNT AS Failed;
END
GO

/* @AdminPasswordEnc NULL or '' on an edit keeps the stored password.
   Making a server the default takes the mark from the previous one. */
CREATE OR ALTER PROCEDURE dbo.sp_Platform_SaveDbServer
    @DbServerId       INT = 0,
    @ServerName       NVARCHAR(200),
    @AdminUser        NVARCHAR(100),
    @AdminPasswordEnc NVARCHAR(500) = NULL,
    @ExtraOptions     NVARCHAR(400) = NULL,
    @IsDefault        BIT = 0,
    @IsActive         BIT = 1
AS
BEGIN
    SET NOCOUNT ON;
    SET XACT_ABORT ON;

    SET @ServerName = LTRIM(RTRIM(ISNULL(@ServerName, '')));
    SET @AdminUser  = LTRIM(RTRIM(ISNULL(@AdminUser, '')));
    SET @IsActive   = ISNULL(@IsActive, 1);
    SET @IsDefault  = CASE WHEN @IsActive = 1 THEN ISNULL(@IsDefault, 0) ELSE 0 END;   -- an inactive server cannot be the default

    IF @ServerName = '' OR @AdminUser = ''
    BEGIN
        SELECT CAST(0 AS INT) AS Success, 'Server and login are required' AS Message, CAST(0 AS INT) AS DbServerId; RETURN;
    END

    IF ISNULL(@DbServerId, 0) = 0 AND ISNULL(@AdminPasswordEnc, '') = ''
    BEGIN
        SELECT CAST(0 AS INT) AS Success, 'Enter the password' AS Message, CAST(0 AS INT) AS DbServerId; RETURN;
    END

    IF ISNULL(@DbServerId, 0) > 0 AND NOT EXISTS (SELECT 1 FROM dbo.DbServers WHERE DbServerId = @DbServerId)
    BEGIN
        SELECT CAST(0 AS INT) AS Success, 'Server not found' AS Message, CAST(0 AS INT) AS DbServerId; RETURN;
    END

    BEGIN TRANSACTION;

    IF @IsDefault = 1
        UPDATE dbo.DbServers WITH (UPDLOCK, HOLDLOCK) SET IsDefault = 0
        WHERE IsDefault = 1 AND DbServerId <> ISNULL(@DbServerId, 0);

    IF ISNULL(@DbServerId, 0) = 0
    BEGIN
        INSERT INTO dbo.DbServers (ServerName, AdminUser, AdminPasswordEnc, ExtraOptions, IsDefault, IsActive)
        VALUES (@ServerName, @AdminUser, @AdminPasswordEnc, NULLIF(LTRIM(RTRIM(@ExtraOptions)), ''), @IsDefault, @IsActive);

        SET @DbServerId = SCOPE_IDENTITY();
    END
    ELSE
        UPDATE dbo.DbServers
        SET ServerName       = @ServerName,
            AdminUser        = @AdminUser,
            AdminPasswordEnc = CASE WHEN ISNULL(@AdminPasswordEnc, '') = '' THEN AdminPasswordEnc ELSE @AdminPasswordEnc END,
            ExtraOptions     = NULLIF(LTRIM(RTRIM(@ExtraOptions)), ''),
            IsDefault        = @IsDefault,
            IsActive         = @IsActive
        WHERE DbServerId = @DbServerId;

    COMMIT TRANSACTION;

    SELECT CAST(1 AS INT) AS Success, 'Server saved' AS Message, @DbServerId AS DbServerId;
END
GO

/* Companies the user is an ACTIVE MEMBER of (a company whose database is not
   ready yet is listed too, with its status). + IsCreator: may retry the set-up. */
CREATE OR ALTER PROCEDURE dbo.sp_User_GetCompanies
    @UserId INT
AS
BEGIN

    SELECT
        c.CompanyId, c.CompanyName, c.CompanyCode, c.Address, c.City, c.PhoneNumber,
        cu.RoleInCompany,

    FROM dbo.CompanyUsers cu

    LEFT  JOIN dbo.UserSessions us ON us.UserId = cu.UserId
    WHERE cu.UserId = @UserId
      AND cu.IsActive = 1
    ORDER BY c.CompanyName;
```

```csharp
using System.Text.RegularExpressions;

namespace EncryptzBL.Common.Provisioning
{
    /// <summary>
    /// New_Tenant_Database.sql as the API runs it. The script is written for a person:
    /// one batch creates #TenantSettings and inserts values that are edited by hand.
    /// The API leaves that batch out and supplies the table itself, with parameters,
    /// on the same connection. If the script ever changes shape this class refuses it,
    /// so a database is never built with settings nobody chose.
    /// </summary>
    public sealed class TenantScript
    {
        /// <summary>Must have exactly the columns the script's own settings table has.</summary>
        public const string CreateSettingsTableSql =
            "CREATE TABLE #TenantSettings (CompanyId INT NOT NULL, ProjectId INT NOT NULL, "
            + "LocationName NVARCHAR(200) NOT NULL, LocationCode NVARCHAR(50) NULL, "
            + "LocationCity NVARCHAR(100) NULL, CopyLookupsFrom SYSNAME NULL);";

        public const string InsertSettingsSql =
            "INSERT INTO #TenantSettings (CompanyId, ProjectId, LocationName, LocationCode, LocationCity, CopyLookupsFrom) "
            + "VALUES (@CompanyId, @ProjectId, @LocationName, @LocationCode, @LocationCity, @CopyLookupsFrom);";

        private static readonly string[] ExpectedColumns =
            { "CompanyId", "ProjectId", "LocationName", "LocationCode", "LocationCity", "CopyLookupsFrom" };

        private static readonly Regex SettingsTable = new(
            @"CREATE\s+TABLE\s+#TenantSettings\s*\((?<columns>.*?)\)\s*;",
            RegexOptions.IgnoreCase | RegexOptions.Singleline | RegexOptions.CultureInvariant);

        private static readonly Regex LineComment = new(@"--[^\n]*", RegexOptions.CultureInvariant);

        private static readonly Regex DatabaseLevel = new(
            @"^\s*((CREATE|ALTER|DROP)\s+DATABASE\b|USE\s+\[)",
            RegexOptions.IgnoreCase | RegexOptions.Multiline | RegexOptions.CultureInvariant);

        private TenantScript(IReadOnlyList<string> batches) => Batches = batches;

        /// <summary>Every batch of the script except the hand-edited settings batch.</summary>
        public IReadOnlyList<string> Batches { get; }

        /// <summary>Where the script is shipped: next to the API's binaries.</summary>
        public static string DefaultPath
            => Path.Combine(AppContext.BaseDirectory, "Database", "ProjectDB", "New_Tenant_Database.sql");

        public static TenantScript Load(string path) => Parse(File.ReadAllText(path));

        public static TenantScript Parse(string text)
        {
            var all = SqlBatchSplitter.Split(text);
            var settings = all.Where(b => SettingsTable.IsMatch(b)).ToList();

            if (settings.Count != 1)
                throw new InvalidOperationException(
                    $"The tenant script must have exactly one settings batch (CREATE TABLE #TenantSettings); found {settings.Count}.");

            var columns = SettingsColumns(settings[0]);
            if (!columns.SequenceEqual(ExpectedColumns, StringComparer.OrdinalIgnoreCase))
                throw new InvalidOperationException(
                    "The settings table of the tenant script has other columns than the API supplies: " + string.Join(", ", columns));

            var batches = all.Where(b => !ReferenceEquals(b, settings[0])).ToList();

            // The database is chosen by the connection: the script must not pick or change one.
            var offending = batches.FirstOrDefault(b => DatabaseLevel.IsMatch(b));
            if (offending != null)
                throw new InvalidOperationException("The tenant script contains a database-level statement (CREATE/ALTER/DROP DATABASE or USE).");

            return new TenantScript(batches);
        }

        private static List<string> SettingsColumns(string batch)
        {
            var body = LineComment.Replace(SettingsTable.Match(batch).Groups["columns"].Value, "");

            return body.Split(',')
                .Select(part => part.Trim().Split(new[] { ' ', '\t', '\n' }, StringSplitOptions.RemoveEmptyEntries).FirstOrDefault() ?? "")
                .Where(name => name.Length > 0)
                .ToList();
        }
    }
}
```

Note for the implementer: the settings table's column list contains `NVARCHAR(200)`: the regex `(?<columns>.*?)\)\s*;` is lazy, so it stops at the first `)` that is followed by `;` — the closing parenthesis of the table, not the one of `NVARCHAR(200)` (which is followed by a space). The split at `,` is safe because no column type there has a comma. If the real-script test fails, print the batch it found and adjust the parsing, not the test.

Create `EncryptzBL/Common/Provisioning/TenantProvisioner.cs`:

```csharp
using Microsoft.Extensions.Logging;

namespace EncryptzBL.Common.Provisioning
{
    /// <summary>
    /// Builds the database of one company and makes the company Ready, or cleans up
    /// and marks it Failed. Rules it guards:
    ///   - the database name comes from the company id only;
    ///   - a database that already exists is never dropped and never reused;
    ///   - only a database THIS attempt created is dropped when the attempt fails;
    ///   - a company that was given up meanwhile does not become Ready.
    /// It never throws: the worker must survive every job.
    /// </summary>
    public sealed class TenantProvisioner
    {
        private const int MaxErrorLength = 2000;   // Companies.ProvisionError

        private readonly IProvisionStore _store;
        private readonly ITenantDatabaseServer _server;
        private readonly ILogger<TenantProvisioner> _logger;

        public TenantProvisioner(IProvisionStore store, ITenantDatabaseServer server, ILogger<TenantProvisioner> logger)
        {
            _store = store;
            _server = server;
            _logger = logger;
        }

        public async Task<ProvisionOutcome> RunAsync(int companyId, CancellationToken ct)
        {
            ProvisionJob? job;
            try
            {
                job = await _store.GetJobAsync(companyId);
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Provisioning of company {CompanyId}: the job could not be read", companyId);
                return ProvisionOutcome.Failed;
            }

            if (job == null || !string.Equals(job.Status, "Provisioning", StringComparison.Ordinal))
                return ProvisionOutcome.Skipped;

            if (string.IsNullOrWhiteSpace(job.ServerName) || string.IsNullOrWhiteSpace(job.AdminUser)
                || string.IsNullOrEmpty(job.AdminPassword))
                return await FailAsync(job, "No usable database server is set for this company.", null);

            var databaseName = TenantDatabaseName.For(job.CompanyId);
            var created = false;

            try
            {
                if (await _server.DatabaseExistsAsync(job, databaseName, ct))
                    return await FailAsync(job,
                        $"A database named {databaseName} already exists on the server. It was not touched. Remove or rename it, then retry.", null);

                await _server.CreateDatabaseAsync(job, databaseName, ct);
                created = true;

                await _server.BuildTenantAsync(job, databaseName, ct);

                if (!await _store.CompleteAsync(job.CompanyId, databaseName))
                    throw new InvalidOperationException("The set-up was given up before it finished.");

                _logger.LogInformation("Provisioning of company {CompanyId}: database ready", job.CompanyId);
                return ProvisionOutcome.Ready;
            }
            catch (Exception ex)
            {
                var reason = ex is OperationCanceledException
                    ? "The set-up timed out."
                    : ex.Message;

                string? leftBehind = null;
                if (created)
                {
                    try
                    {
                        await _server.DropDatabaseAsync(job, databaseName);
                    }
                    catch (Exception dropEx)
                    {
                        _logger.LogError(dropEx, "Provisioning of company {CompanyId}: the database of the failed attempt could not be removed", job.CompanyId);
                        leftBehind = $" The database {databaseName} could not be removed and was left on the server: remove it before retrying.";
                    }
                }

                _logger.LogError(ex, "Provisioning of company {CompanyId} failed", job.CompanyId);
                return await FailAsync(job, reason, leftBehind);
            }
        }

        private async Task<ProvisionOutcome> FailAsync(ProvisionJob job, string reason, string? leftBehind)
        {
            // the note about a database left behind must survive the truncation
            var note = leftBehind ?? "";
            var text = Scrub(reason, job);
            var room = Math.Max(0, MaxErrorLength - note.Length);
            if (text.Length > room)
                text = text.Substring(0, room);

            try
            {
                await _store.FailAsync(job.CompanyId, text + note);
            }
            catch (Exception ex)
            {
                // the stuck-job sweeper will mark it Failed later
                _logger.LogError(ex, "Provisioning of company {CompanyId}: the failure could not be recorded", job.CompanyId);
            }

            return ProvisionOutcome.Failed;
        }

        /// <summary>An error text must never carry the server password.</summary>
        private static string Scrub(string text, ProvisionJob job)
        {
            var result = text ?? "";
            if (!string.IsNullOrEmpty(job.AdminPassword))
                result = result.Replace(job.AdminPassword, "***", StringComparison.Ordinal);
            return result;
        }
    }
}
```

```csharp
using EncryptzBL.Common.Tenant;
using Microsoft.Data.SqlClient;

namespace EncryptzBL.Common.Provisioning
{
    /// <summary>
    /// Creates, builds and (for a failed attempt) drops a company database on the
    /// server of the job. The only text ever concatenated into SQL here is a database
    /// name that <see cref="TenantDatabaseName.IsGenerated"/> accepts.
    /// </summary>
    public sealed class SqlTenantDatabaseServer : ITenantDatabaseServer
    {
        /// <summary>Per batch of the tenant script.</summary>
        public const int BatchTimeoutSeconds = 300;

        private readonly Lazy<TenantScript> _script;

        public SqlTenantDatabaseServer(Lazy<TenantScript> script) => _script = script;

        public static string CreateDatabaseSql(string databaseName)
            => $"CREATE DATABASE [{Checked(databaseName)}];";

        public static string DropDatabaseSql(string databaseName)
        {
            var name = Checked(databaseName);
            return $"IF DB_ID(N'{name}') IS NOT NULL BEGIN "
                 + $"ALTER DATABASE [{name}] SET SINGLE_USER WITH ROLLBACK IMMEDIATE; "
                 + $"DROP DATABASE [{name}]; END";
        }

        private static string Checked(string databaseName)
            => TenantDatabaseName.IsGenerated(databaseName)
                ? databaseName
                : throw new InvalidOperationException("Not a generated tenant database name.");

        public async Task<bool> DatabaseExistsAsync(ProvisionJob job, string databaseName, CancellationToken ct)
        {
            await using var conn = new SqlConnection(Master(job));
            await conn.OpenAsync(ct);

            await using var cmd = new SqlCommand("SELECT DB_ID(@Name);", conn);
            cmd.Parameters.AddWithValue("@Name", databaseName);

            var id = await cmd.ExecuteScalarAsync(ct);
            return id != null && id != DBNull.Value;
        }

        public async Task CreateDatabaseAsync(ProvisionJob job, string databaseName, CancellationToken ct)
        {
            await using var conn = new SqlConnection(Master(job));
            await conn.OpenAsync(ct);

            await using var cmd = new SqlCommand(CreateDatabaseSql(databaseName), conn) { CommandTimeout = 120 };
            await cmd.ExecuteNonQueryAsync(ct);
        }

        public async Task BuildTenantAsync(ProvisionJob job, string databaseName, CancellationToken ct)
        {
            var script = _script.Value;   // throws when the shipped script does not have the expected shape

            // One connection for everything: #TenantSettings lives in the session.
            // Not pooled, so nothing keeps the database open if it has to be dropped.
            await using var conn = new SqlConnection(Tenant(job, Checked(databaseName)));
            await conn.OpenAsync(ct);

            // A parameterised command runs inside sp_executesql, where a temporary table
            // would vanish at once: create it with a plain command, fill it with parameters.
            await using (var create = new SqlCommand(TenantScript.CreateSettingsTableSql, conn))
                await create.ExecuteNonQueryAsync(ct);

            await using (var insert = new SqlCommand(TenantScript.InsertSettingsSql, conn))
            {
                insert.Parameters.AddWithValue("@CompanyId", job.CompanyId);
                insert.Parameters.AddWithValue("@ProjectId", job.TenantScopeId);
                insert.Parameters.Add("@LocationName", System.Data.SqlDbType.NVarChar, 200).Value = job.FirstBranchName;
                insert.Parameters.Add("@LocationCode", System.Data.SqlDbType.NVarChar, 50).Value = DBNull.Value;
                insert.Parameters.Add("@LocationCity", System.Data.SqlDbType.NVarChar, 100).Value = DBNull.Value;
                insert.Parameters.Add("@CopyLookupsFrom", System.Data.SqlDbType.NVarChar, 128).Value =
                    string.IsNullOrWhiteSpace(job.LookupSourceDb) ? DBNull.Value : job.LookupSourceDb.Trim();
                await insert.ExecuteNonQueryAsync(ct);
            }

            var number = 0;
            foreach (var batch in script.Batches)
            {
                number++;
                ct.ThrowIfCancellationRequested();

                try
                {
                    await using var cmd = new SqlCommand(batch, conn) { CommandTimeout = BatchTimeoutSeconds };
                    await cmd.ExecuteNonQueryAsync(ct);
                }
                catch (SqlException ex)
                {
                    // the script's own safety checks raise an error and switch NOEXEC on: stop at once
                    throw new InvalidOperationException($"Tenant script batch {number} of {script.Batches.Count} failed: {ex.Message}", ex);
                }
            }

            await VerifyAsync(conn, ct);
        }

        /// <summary>The same readiness test "Test connection" uses, plus the first branch.</summary>
        private static async Task VerifyAsync(SqlConnection conn, CancellationToken ct)
        {
            // the script ends with SET NOEXEC OFF, but be sure before asking
            await using (var off = new SqlCommand("SET NOEXEC OFF;", conn))
                await off.ExecuteNonQueryAsync(ct);

            const string sql = @"SELECT
                CASE WHEN OBJECT_ID('dbo.Locations') IS NOT NULL
                      AND OBJECT_ID('dbo.sp_Project_GetLocations') IS NOT NULL
                      AND OBJECT_ID('dbo.sp_Location_Validate') IS NOT NULL
                      AND OBJECT_ID('dbo.sp_Tenant_SyncUsers') IS NOT NULL
                      AND COL_LENGTH('dbo.Users', 'MainUserId') IS NOT NULL
                     THEN 1 ELSE 0 END;";

            await using (var ready = new SqlCommand(sql, conn))
            {
                if (Convert.ToInt32(await ready.ExecuteScalarAsync(ct)) != 1)
                    throw new InvalidOperationException("The tenant script ran but the database is not complete.");
            }

            await using var branches = new SqlCommand("SELECT COUNT(*) FROM dbo.Locations WHERE IsActive = 1;", conn);
            if (Convert.ToInt32(await branches.ExecuteScalarAsync(ct)) < 1)
                throw new InvalidOperationException("The tenant script ran but no branch was created.");
        }

        public async Task DropDatabaseAsync(ProvisionJob job, string databaseName)
        {
            await using var conn = new SqlConnection(Master(job));
            await conn.OpenAsync();

            await using var cmd = new SqlCommand(DropDatabaseSql(databaseName), conn) { CommandTimeout = 120 };
            await cmd.ExecuteNonQueryAsync();
        }

        private static string Master(ProvisionJob job)
            => new SqlConnectionStringBuilder(
                   TenantConnectionString.Build(job.ServerName, "master", job.AdminUser, job.AdminPassword, job.ExtraOptions))
               { Pooling = false, ConnectTimeout = 15 }.ConnectionString;

        private static string Tenant(ProvisionJob job, string databaseName)
            => new SqlConnectionStringBuilder(
                   TenantConnectionString.Build(job.ServerName, databaseName, job.AdminUser, job.AdminPassword, job.ExtraOptions))
               { Pooling = false, ConnectTimeout = 15 }.ConnectionString;
    }
}
```

```csharp
    /// has about 1,470 batches and can outlast a proxy time-out), and gives up jobs
    /// that were interrupted.
    /// </summary>
    public sealed class ProvisioningWorker : BackgroundService
    {
        /// <summary>A job ends, and cleans up, before the sweeper would give it up.</summary>
        public static readonly TimeSpan JobTimeout = TimeSpan.FromMinutes(12);
        public const int StuckAfterMinutes = 15;
        public static readonly TimeSpan SweepEvery = TimeSpan.FromMinutes(5);

        private readonly ProvisioningQueue _queue;
        private readonly IServiceScopeFactory _scopes;
        private readonly ILogger<ProvisioningWorker> _logger;

        public ProvisioningWorker(ProvisioningQueue queue, IServiceScopeFactory scopes, ILogger<ProvisioningWorker> logger)
        {
            _queue = queue;
            _scopes = scopes;
            _logger = logger;
        }

        protected override async Task ExecuteAsync(CancellationToken stoppingToken)
        {
            // let the host finish starting before the first database call
            await Task.Yield();

            await Task.WhenAll(RunJobsAsync(stoppingToken), SweepAsync(stoppingToken));
        }

        private async Task RunJobsAsync(CancellationToken stoppingToken)
        {
            try
            {
                await foreach (var companyId in _queue.Reader.ReadAllAsync(stoppingToken))
                    await RunOneAsync(companyId, stoppingToken);
            }
            catch (OperationCanceledException) { /* the host is stopping */ }
        }

        private async Task RunOneAsync(int companyId, CancellationToken stoppingToken)
        {
            try
            {
                using var scope = _scopes.CreateScope();
                using var timeout = CancellationTokenSource.CreateLinkedTokenSource(stoppingToken);
                timeout.CancelAfter(JobTimeout);

                var provisioner = scope.ServiceProvider.GetRequiredService<TenantProvisioner>();
                var outcome = await provisioner.RunAsync(companyId, timeout.Token);

                // the creator must exist in the new database before the first login into it
                if (outcome == ProvisionOutcome.Ready)
                    await scope.ServiceProvider.GetRequiredService<ITenantUserSyncService>()
                               .TrySyncCompanyUsersAsync(companyId);
            }
            catch (Exception ex)
            {
                // never let one job stop the worker
                _logger.LogError(ex, "Provisioning worker: job of company {CompanyId} ended unexpectedly", companyId);
            }
        }

        private async Task SweepAsync(CancellationToken stoppingToken)
        {
            try
            {
                using var timer = new PeriodicTimer(SweepEvery);
                do
                {
                    try
                    {
                        using var scope = _scopes.CreateScope();
                        var failed = await scope.ServiceProvider.GetRequiredService<IProvisionStore>()
                                                .FailStuckAsync(StuckAfterMinutes);
                        if (failed > 0)
                            _logger.LogWarning("Provisioning worker: {Count} interrupted set-up(s) marked as failed", failed);
                    }
                    catch (Exception ex)
                    {
                        // e.g. script 20 has not been run yet: company creation is simply not available
                        _logger.LogWarning(ex, "Provisioning worker: the check for interrupted set-ups failed");
                    }
                }
                while (await timer.WaitForNextTickAsync(stoppingToken));
            }
            catch (OperationCanceledException) { /* the host is stopping */ }
        }
    }
}
```

```csharp
        public async Task<ApiResponse<CompanyCreatedDto>> CreateCompany(CreateCompanyRequest req, int userId, bool isPlatformAdmin)
        {
            if (userId <= 0)
                return ApiResponse<CompanyCreatedDto>.Fail("Please log in again");

            var (company, error) = CompanyCreateRules.Normalize(
                req?.CompanyName, req?.CompanyCode, req?.FirstBranchName, req?.Address, req?.City, req?.PhoneNumber);

            if (company == null)
                return ApiResponse<CompanyCreatedDto>.Fail(error ?? "Check the company details");

            var dt = await GetDataTableAsync("sp_Company_Create", new[]
            {
                SqlParameterHelper.Input("@CompanyName", company.CompanyName),
                SqlParameterHelper.Input("@CompanyCode", company.CompanyCode),
                SqlParameterHelper.Input("@Address", (object?)company.Address ?? DBNull.Value),
                SqlParameterHelper.Input("@City", (object?)company.City ?? DBNull.Value),
                SqlParameterHelper.Input("@PhoneNumber", (object?)company.PhoneNumber ?? DBNull.Value),
                SqlParameterHelper.Input("@FirstBranchName", company.FirstBranchName),
                SqlParameterHelper.Input("@CreatedBy", userId),
                SqlParameterHelper.Input("@IsPlatformAdmin", isPlatformAdmin)
            });

            if (dt == null || dt.Rows.Count == 0)
                return ApiResponse<CompanyCreatedDto>.Fail("The company could not be created. Please try again.");

            var message = dt.Rows[0]["Message"]?.ToString() ?? "";
            if (Convert.ToInt32(dt.Rows[0]["Success"]) != 1)
                return ApiResponse<CompanyCreatedDto>.Fail(message);

            var companyId = Convert.ToInt32(dt.Rows[0]["CompanyId"]);
            _logger.LogInformation("Company {CompanyId} created by user {UserId}; database set-up queued", companyId, userId);

            _queue.Enqueue(companyId);

            return ApiResponse<CompanyCreatedDto>.Ok(new CompanyCreatedDto { CompanyId = companyId }, message);
        }

        public async Task<ApiResponse<bool>> RetryProvision(int companyId, int userId, bool isPlatformAdmin)
        {
            if (companyId <= 0 || userId <= 0)
                return ApiResponse<bool>.Fail("Company not found");

            var dt = await GetDataTableAsync("sp_Provision_Retry", new[]
            {
                SqlParameterHelper.Input("@CompanyId", companyId),
                SqlParameterHelper.Input("@UserId", userId),
                SqlParameterHelper.Input("@IsPlatformAdmin", isPlatformAdmin)
            });

            if (dt == null || dt.Rows.Count == 0)
                return ApiResponse<bool>.Fail("Please try again");

            var message = dt.Rows[0]["Message"]?.ToString() ?? "";
            if (Convert.ToInt32(dt.Rows[0]["Success"]) != 1)
                return ApiResponse<bool>.Fail(message);

            _logger.LogInformation("Database set-up of company {CompanyId} queued again by user {UserId}", companyId, userId);
            _queue.Enqueue(companyId);

            return ApiResponse<bool>.Ok(true, message);
        }

            {

            });

            if (dt == null || dt.Rows.Count == 0)

                Created = created,
                Limit = limit,
                Message = reason ?? ""
            });
```

```csharp
        public async Task<ApiResponse<int>> SaveDbServer(SaveDbServerRequest req, PlatformActor actor)
        {
            if (!actor.IsPlatformAdmin)
                return ApiResponse<int>.Fail(NotAllowed);

            if (req == null || string.IsNullOrWhiteSpace(req.ServerName) || string.IsNullOrWhiteSpace(req.AdminUser))
                return ApiResponse<int>.Fail("Server and login are required");

            if (req.ServerName.Trim().Length > 200 || req.AdminUser.Trim().Length > 100 || (req.ExtraOptions?.Length ?? 0) > 400)
                return ApiResponse<int>.Fail("One of the values is too long");

            // stored encrypted; empty on an edit keeps the stored one
            var encrypted = string.IsNullOrEmpty(req.AdminPassword) ? null : _protector.Protect(req.AdminPassword);

            var dt = await GetDataTableAsync("sp_Platform_SaveDbServer", new[]
            {
                SqlParameterHelper.Input("@DbServerId", req.DbServerId),
                SqlParameterHelper.Input("@ServerName", req.ServerName.Trim()),
                SqlParameterHelper.Input("@AdminUser", req.AdminUser.Trim()),
                SqlParameterHelper.Input("@AdminPasswordEnc", (object?)encrypted ?? DBNull.Value),
                SqlParameterHelper.Input("@ExtraOptions", Nullable(req.ExtraOptions)),
                SqlParameterHelper.Input("@IsDefault", req.IsDefault),
                SqlParameterHelper.Input("@IsActive", req.IsActive)
            });

            var result = ToResult(dt, "DbServerId");
            if (result.Success)
                _logger.LogInformation("Database server {DbServerId} saved by user {UserId} (default: {IsDefault})",
                    result.Data, actor.UserId, req.IsDefault);

            return result;
        }

        /// <summary>Can the API log in, and may that login create databases?</summary>
        public async Task<ApiResponse<ConnectionTestResult>> TestDbServer(SaveDbServerRequest req, PlatformActor actor)
        {
            if (!actor.IsPlatformAdmin)
                return ApiResponse<ConnectionTestResult>.Fail(NotAllowed);

            if (req == null || string.IsNullOrWhiteSpace(req.ServerName) || string.IsNullOrWhiteSpace(req.AdminUser))
                return ApiResponse<ConnectionTestResult>.Fail("Server and login are required");

            var password = req.AdminPassword;

            // editing without retyping the password: test with the stored one
            if (string.IsNullOrEmpty(password) && req.DbServerId > 0)
            {
                var stored = await GetDataTableAsync("sp_Platform_GetDbServerSecret", new[]
                {
                    SqlParameterHelper.Input("@DbServerId", req.DbServerId)
                });

                if (stored != null && stored.Rows.Count > 0)
                {
                    try { password = _protector.Unprotect(stored.Rows[0]["AdminPasswordEnc"]?.ToString() ?? ""); }
                    catch { password = null; }
                }
            }

            if (string.IsNullOrEmpty(password))
                return ApiResponse<ConnectionTestResult>.Fail("Enter the password to test the connection");

            var result = new ConnectionTestResult();

            try
            {
                var connectionString = new SqlConnectionStringBuilder(
                    TenantConnectionString.Build(req.ServerName, "master", req.AdminUser, password, req.ExtraOptions))
                { ConnectTimeout = 10, Pooling = false }.ConnectionString;

                var master = new ExplicitDbHelper(connectionString);
                var dt = await master.ExecuteQueryDataTableAsync(
                    "SELECT CASE WHEN IS_SRVROLEMEMBER('dbcreator') = 1 OR IS_SRVROLEMEMBER('sysadmin') = 1 THEN 1 ELSE 0 END AS CanCreate");

                result.Connected = true;
                result.SchemaReady = dt.Rows.Count > 0 && Convert.ToInt32(dt.Rows[0]["CanCreate"]) == 1;
                result.Message = result.SchemaReady
                    ? "Connected. This login can create databases"
                    : "Connected, but this login cannot create databases. Give it the dbcreator server role";
            }
            catch (Exception ex) when (ex is SqlException || ex is ArgumentException || ex is FormatException)
            {
                // never the exception text: it can name the server and the login
                _logger.LogWarning(ex, "Connection test of a database server failed (user {UserId})", actor.UserId);
                result.Message = "Could not connect. Check the server, login, password and options";
            }

            return ApiResponse<ConnectionTestResult>.Ok(result, result.Message);
        }

        public async Task<ApiResponse<bool>> SaveSetting(SavePlatformSettingRequest req, PlatformActor actor)
        {
            if (!actor.IsPlatformAdmin)
                return ApiResponse<bool>.Fail(NotAllowed);

            var (value, error) = PlatformSettingRules.Validate(req?.SettingKey, req?.SettingValue);
            if (value == null)
                return ApiResponse<bool>.Fail(error ?? "Unknown setting");

            var dt = await GetDataTableAsync("sp_Platform_SaveSetting", new[]
            {
                SqlParameterHelper.Input("@SettingKey", req!.SettingKey),
                SqlParameterHelper.Input("@SettingValue", value),
                SqlParameterHelper.Input("@UpdatedBy", actor.UserId)
            });

            var result = ToFlag(dt);
            if (result.Success)
                _logger.LogInformation("Platform setting {SettingKey} changed by user {UserId}", req.SettingKey, actor.UserId);

            return result;
        }
```
